# Metronom pro Toma a kapelu

Sekční metronom, který si pamatuje tempo, takt a polyrytmy pro každou část
skladby zvlášť. Funguje přímo v prohlížeči, bez instalace.

## Použití

Otevřete `index.html` v prohlížeči, nebo si aplikaci nasaďte přes GitHub
Pages:

1. **Settings → Pages** v tomto repozitáři
2. Branch: `main`, složka `/ (root)`
3. Uložit — za chvíli se objeví veřejný odkaz

## Funkce

- Libovolný počet částí skladby, každá s vlastním tempem, taktem a délkou
- Polyrytmické vrstvy (např. 3 proti 4) s vlastním zvukem pro každou vrstvu
- Export/import skladby jako JSON, export klikací stopy jako WAV
- Tempo poklepáním, přetažením, kolečkem myši nebo přímým zadáním čísla
- Aplikace si pamatuje nastavení částí se stejným názvem (např. "Chorus")
- Podpora ovládání na uzamčené obrazovce telefonu (Media Session API)
